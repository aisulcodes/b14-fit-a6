# FitLog

FitLog is a simple workout website. Users can explore different workouts, see workout details, add workouts to their plan, and save workouts for later.

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- Context API
- LocalStorage
- REST API

## Key Features

1. **Workout Library**
   - Users can see different workouts and basic workout information.

2. **Workout Details**
   - Users can click a workout and see its details, such as equipment, duration, calories, sets, and reps.

3. **Add to My Plan**
   - Users can add a workout to their today's plan.

4. **Save for Later**
   - Users can save a workout and check it later from the Saved section.

5. **My Plan**
   - Users can see their planned and saved workouts and remove them when needed.
